# Youffx2 Kernel Build Project

Custom Android kernel build repository for **Xiaomi Rosemary (MT6785)** with **KernelSU** and **SUSFS** integration profiles.

## What this repo does
- Stores build configurations in `configs/builds.json`.
- Runs GitHub Actions workflows to clone kernel sources, apply KernelSU/KernelSU-Next setup scripts and optional patches, then compile flashable kernel ZIPs.
- Supports multiple build profiles (KSU, NONKSU, SUSFS variants).

## Repositories used
- Main project: https://github.com/lkv414/Youffx2
- Kernel source: https://github.com/lkv414/kernel_xiaomi_rosemary
- KernelSU: https://github.com/lkv414/KernelSU
- KernelSU-Next: https://github.com/lkv414/KernelSU-Next
